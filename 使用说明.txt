TagMaster · 打标高手
========================================

缺东西跑不起来？先看 README.md —— 里面写了每个目录该放什么。
程序启动时也会自动检查，缺什么会弹窗列出来。

三个功能，顶部三个标签切换：
  ① 打标          —— 给一堆片段自动贴 8 个字段的标签
  ② 切片段        —— 读 PR 导出的 XML，把里面的剪辑点全部切出来
  ③ 素材库        —— 把库里已有的老素材按文件名建标签表（不改名、不复制）


========================================
① 打标
========================================

普通用法
  1. 素材目录：选装着一堆短片的文件夹（比如 D:\素材\cut_01）
  2. 输出目录：会自动填「素材目录_打标」，可以改
  3. 每段抽帧：默认 2，别动
  4. 点「开始打标」

关于两个目录（重要）
  · 程序里没有写死任何路径 —— 没有固定盘符，也不要求放某个文件夹。
    素材目录、输出目录都可以任意选：D 盘 E 盘移动硬盘都行，
    中文名、空格、很深的层级都支持。
  · 输出目录留空时自动推导为「素材目录名_打标」；填了就以你填的为准。
  · 唯一会「记住」的是程序目录里的 设置.json，只是省得每次重选。
    换电脑、换位置、删掉它都无所谓，重新选一下目录即可，不影响任何数据。
  · 换台电脑用：把程序文件夹整个拷过去就能跑，路径全按你自己选的走。

跑完输出目录里会有：

  clips\          改名后的副本（原片一个字节都不动）
  thumbs\         缩略图
  tags.csv        标签表，Excel 能直接打开
  preview.html    双击打开，可按景别/人数/朝向/光线/情绪/场景筛选
  cache\          抽帧缓存，别删 —— 续跑靠它跳过重复抽帧
  解析失败.txt     只有出错时才有，里面是失败原因 + 模型原始输出

文件名格式：
  景别_人数_朝向_主体_动作_场景_光线_情绪_编号.mp4
  例：中景_单人_侧脸_少女 金发_站立_森林_白天_平静_0183.mp4

标签表还多四列（不进文件名，只在 tags.csv 和预览页里筛）：
  风格（赛璐璐/厚涂/水彩/3D/实拍/线稿）
  色调（冷/暖/中性/黑白/高饱和/低饱和）
  字幕（有/无）
  运镜（固定/推/拉/摇/移/跟/慢镜头/第一人称/手持/变速）
  —— 前三个由模型判断；运镜模型只看静帧判不准，只在「导入已有片段」时
     按文件名填（比如名字里有「慢镜头」「第一人称」）。

每个片段约 2.5 秒，400 个大概 17 分钟。

素材库模式（勾「直接存入素材库文件夹」）
  勾上后，输出目录就直接当成你的作品文件夹用：
    · 片段不建 clips 子目录，直接落在该文件夹里
    · 名字改成手写风格：景别 光线 主体 动作 场景.mp4（空格分隔、无编号）
      例：全景 夜晚 金发少女 撑伞 水面.mp4
    · 撞名自动加 -2、-3，绝不覆盖已有文件
    · 标签表、预览页、缩略图、缓存都收进该文件夹的 _标签数据\ 里
    · 同一个文件夹再打第二批，标签表自动追加合并
  适合：D:\素材库\<作品名> 这种按作品分好的素材库。

  提示：选到 _标签数据 里会自动退回上一级；
        选到已有视频的文件夹时会自动勾上这个模式。

只补标签（勾「只补标签（不改名、不复制）」）
  给库里自己手写过名字的老素材补全字段时用：
    · 素材目录 = 要补的那部作品文件夹，输出目录那一格会被忽略
      （勾上后「输出目录」和「直接存入素材库文件夹」会自动变灰，不用管它们）
    · 视频原地不动：不改名、不复制、不移动、不删除
    · 标签写回 <素材目录>\_标签数据\tags.csv，预览页同步更新
    · 已有记录沿用原编号，新片段接在最大编号之后
    · 改过名 / 删掉的旧记录会被清掉，日志会写「清理失效记录 N 条」
  适合：名字只有「中景 夜晚 女主咬勋章」，想补上情绪、场景、动作这些
        名字里没写的字段，好让预览页也能按它们筛。

  和「导入已有片段」的区别：
    导入已有片段 → 只读文件名，每个约 0.15 秒，不跑模型，字段不全
    只补标签     → 跑模型看图，每个约 2.5 秒，8 个字段基本都能填上

其它顺手功能
  · 拖入识别：把文件夹 / PR XML 直接拖进窗口，自动填好对应路径
    还可以把预览页导出的 tm_cmd.json 拖进来 —— 会转发给 Premiere
  · 记住上次选项：路径和勾选项存在程序目录的 设置.json 里，
    开始任务或关窗时保存，下次打开自动恢复
  · 续跑：勾上后，已有完整标签的片段直接跳过，只补没打过的
  · 跑完点名失败：日志最后会写「本次失败 N 个：xxx.mp4」，
    勾「续跑」再点一次就只重试这几个

发送到 Premiere（先装面板，装法见下）
  把片段直接送进 PR 的项目面板，不用开文件夹翻：
    · 预览页勾选片段 → 点「发送到 Premiere」：
      TagMaster 开着 → 直接发送，PR 面板 1 秒内收到（最顺手）；
      TagMaster 没开 → 自动下载 tm_cmd.json，拖进 TagMaster 窗口即送达
    · ③ 素材库页 / ① 打标页点「发送到 Premiere」：整批发送
    · PR 面板里也能挑：面板顶部「浏览…」选素材文件夹，
      列出视频（可按文件名过滤），勾选后「导入选中」
  片段直接导入项目根目录下以作品名命名的 bin（如「某部作品」）。

安装 PR 面板（一次性，约 1 分钟）
  1. 普通 cmd 执行（不用管理员）：
     reg add "HKCU\Software\Adobe\CSXS.12" /v PlayerDebugMode /t REG_SZ /d 1 /f
     （CSXS.9 / .10 / .11 也建议各跑一遍，旧版 PR 才能认）
  2. 把程序目录的 cep\tagmaster-panel 整个文件夹拷到：
     %APPDATA%\Adobe\CEP\extensions\com.tagmaster.prpanel\
     （extensions 不存在就新建）
  3. 完全关闭 Premiere 再打开 → 窗口 → 扩展程序 → TagMaster 素材桥
  4. 面板显示「监听中」就装好了。
  注意：这套面板要装在「装了 Premiere 的那台电脑」上；
        命令桥参考 TuanToolKit 原作者的设计，命令文件不冲突，可同装。


========================================
② 切片段
========================================

PR 里的操作：场景编辑检测 → 文件 → 导出 → Final Cut Pro XML

  1. XML 文件：选刚导出的那个 xml
  2. 输出目录：自动填「xml名_clips」
  3. 源视频目录：填原片现在所在的文件夹
     （挪过位置就靠这一项，程序按文件名去这个目录里找）
  4. 路径替换：另一种办法，填「旧目录 → 新目录」，效果一样
  5. 点「开始切片段」

输出：序列名_0001.mp4、序列名_0002.mp4……
      顺序就是时间线上的顺序。

418 个片段大约 4 分钟（NVENC 硬件编码，失败自动切 CPU）。

注意：
  · 只取第一轨视频。PR 场景检测出来的都是单轨，正常。
  · 多轨剪辑会把所有轨道的片段都切出来，按时间线顺序编号。
  · 「保留音频」默认不勾，剪 MAD 用不到，勾上会慢一点。
  · 切完可以直接点「切完去打标 →」，自动把输出目录填进打标页。


========================================
③ 素材库（导入已有片段）
========================================

作用：你以前手动命名、手动分好类的老素材，不用重新跑模型，
      也能进标签表、进预览页，按关键词搜、按景别筛。

注意：这一页的「库文件夹」和打标页的「素材目录 / 输出目录」是两回事，
      这里只读已有文件，不会往里面复制任何东西。

用法：
  1. 切到「③ 素材库」页
  2. 库文件夹：选单部作品文件夹，或包含多部作品的总库目录
     （选好后会显示「单部作品：N 个视频」或「总库：N 个子文件夹」）
  3. 点「导入已有片段」
  4. 等进度条走完（每个片段约 0.15 秒，主要是生成缩略图）

它会做什么：
  · 读文件名，能认的标签认出来：
      中景 夜晚 女主咬勋章.mp4
      → 景别=中景  光线=夜晚  主体=女主咬勋章
  · 「混合」这类你自己分的类别也会原样保留到景别列（近景/中景/空镜/远景等都认）
  · 名字里的场景词（室内/天空/森林…）、风格（水彩/厚涂…）、色调（黑白/冷色调…）、
    运镜（慢镜头/第一人称/固定…）也会认出并填进对应列
  · 认不出的部分整段放进「主体」，预览页照样能搜到
  · 每部作品生成自己的 _标签数据\（标签表 + 预览页 + 缩略图）
  · 选总库目录时逐个作品导入，不用一部一部点
  · 每次点都会按当前文件名重新解析（改了名或词表更新后，重跑一次即可生效）

它不会做什么：
  · 不改名、不复制、不移动、不删除任何视频
  · 已经导入过的自动跳过，重复点不会重复加行

底部按钮：打开文件夹 / 打开预览页 / 打开标签表 / 生成全库预览。

全库搜索（跨作品）
  1. 库文件夹选总库目录（比如 D:\素材库，包含各作品子文件夹的那层）
  2. 点底部「生成全库预览」
  3. 自动打开 全库预览.html：所有作品的片段混在一页里，
     多了一行「作品」筛选，搜索框也能直接搜作品名
  同时会在总库目录生成 全库标签.csv（多一列「作品」，Excel 可筛）

  注意：它合并的是各作品 _标签数据\tags.csv，所以每次导入新作品
        或重新打标后，要再点一次才会更新。每部作品自己的预览页仍然保留。

改了文件名怎么办？
  · 模型打标的片段：再点一次「导入已有片段」，程序会按文件大小把旧记录
    自动认领到新名字上，标签不丢（同尺寸文件唯一时才会认领）
  · 你手写命名的片段：直接按新名字重新解析，旧记录自动清掉
  · 认领不了的（比如两个文件大小完全一样）会清掉那行，日志里会写
    「清理失效记录 N 条」，按新名字重新导入即可
  · 改完名字记得再点一次「生成全库预览」

提醒：名字里没写的东西（情绪、动作细类）导进来也是空的，
      想补只能之后用模型补标。


========================================
出问题怎么办
========================================

1. 双击没反应
   看本目录下有没有生成「启动错误.log」，有的话把内容发我。

2. 拖进去没反应
   日志里搜「拖放」，正常会有一行「拖放已就绪：已启用」。
   没有说明被系统拦了：改用「浏览」按钮，或者把文件直接拖到
   TagMaster.bat 图标上启动。

3. 切片段提示「全部源文件都找不到」
   说明原片挪了位置。在「源视频目录」里选原片现在所在的文件夹；
   如果文件名也改了，就在「路径替换」里填旧目录和新目录。

4. 提示显存不足
   先关掉其它吃显存的程序（游戏、剪辑软件、浏览器视频）。
   MiniCPM 约占 3G，DinoV2 约占 1.5G，8G 显存够用但不宽裕。

5. 某个片段被跳过
   现在分两种，日志会写清楚：
     · 跳过（抽不到帧）：片段损坏或没有视频流
     · 跳过（解析失败）：模型输出不对，会带上具体原因
   跑完最后一行会点名所有失败片段；详细原因和模型原文在
   输出目录的 解析失败.txt 里。
   勾「续跑」再点一次，只重试这几个，不影响已完成的。

6. 预览页打不开 / 打开是空的
   普通模式：preview.html 在输出目录根下。
   素材库模式：preview.html 在 输出目录\_标签数据\ 里。
   点底部「打开预览页」会自动找这两个位置。


========================================
目录里都是什么
========================================

  python\            运行环境（含 torch、transformers，5.3G）
  models\            模型
    MiniCPM-V-4-6\     打标签用的多模态模型（2.5G）
    aslakey_shot_scale\ 判景别用的分类模型（1.2G）
    ffmpeg\            抽帧、切片
  A_coreUtils\       两个模型调用模块
  TagMaster.py       主程序（界面 + 流程都在里面）
  TagMaster.bat      启动器
  设置.json          上次用过的路径和勾选项（自动生成，删了就恢复默认）

  原片、切出来的片段、素材库放哪都行，不要求在程序目录里。
  上面这些只有 python\ models\ A_coreUtils\ 是程序必须的。


========================================
已知短板
========================================

· 情绪判断偏保守，大部分会落在「平静/孤独」，别太当真
· 看不到正脸时「朝向」可能判错（兜帽、暗光、远景）
· 景别实际只有五档（大特写/特写/中景/全景/远景）+ 空镜；
  「近景」只在景别模型判不出来时才可能沿用标签模型给的值
· 导入已有片段时，情绪/人数/朝向只能从文件名里认，名字没写就是空的
